## Slide 2 — About RabbitMQ

- RabbitMQ is an open-source distributed message/streaming broker.
- RabbitMQ supports AMQP (Advanced Message Queuing Protocol), MQTT (Message Queue Telemetry Transport protocol)
- AMQP, MQTT are an open standard **application layer protocols**.
- RabbitMQ accepts, stores, and forwards *messages*: blobs of data

## Slide 3 — Jargons

![Slide 3](../png/page-03.png)

| Term | Definition | Symbol |
|---|---|---|
| **Producing** | A program which sends message is a *producer*. | cyan circle **P** |
| **Queue** | a post box living inside RabbitMQ. | red box of slots labelled `queue_name` |
| **Consuming** | A *consumer* is a program that mostly waits to receive messages. | cyan circle **C** |

**RabbitMQ is a push model.** — Queue sends message to consumers

## Slide 4 — Overview of the tutorial patterns

![Slide 4](../png/page-04.png)

Diagram: the seven RabbitMQ tutorial patterns drawn with the P / queue / X (exchange) / C symbols: (1) Hello world (P → queue → C), (2) Work queues (P → queue → C1, C2; "The competing consumer pattern"), (3) Publish/Subscribe (P → X → two queues via *binding*), (4) Routing (P → X type=direct → Q1 via `orange`, Q2 via `black`, `green` → C1, C2), (5) Topics (P → X type=topic → Q1 via `*.orange.*`, Q2 via `*.*.rabbit`, `lazy.#`), (6) RPC (Client C → `rpc_queue` → Server S with `reply_to=amqp.gen-Xa2…`, `correlation_id=abc`), and (7) Publisher confirms.

- (1) Hello world
- (2) Work queues — The competing consumer pattern
- (3) Publish/Subscribe — Exchange type: direct, topic, headers, **fanout**
- (4) Routing — Exchange type: **direct**, topic, headers, fanout; *binding key == routing key*
- (5) Topics — `*` Can substitute for exactly one word; `#` Can substitute for zero or more words
- (6) RPC
- (7) Publisher confirms

# Part 2 — (1) Hello world

## Slide 9 — (1) Hello world: Producer (P)

Pattern: P → queue → C. Run `python 1_HelloReceive.py` and `python 1_HelloSent.py`.

```python
import sys

#!/usr/bin/env python
import pika

connection = pika.BlockingConnection(pika.ConnectionParameters('localhost'))
channel = connection.channel()
channel.queue_declare(queue='hello', durable=True)

channel.basic_publish(exchange='',
                      routing_key='hello',
                      body='Hello World!')
print(" [x] Sent 'Hello World!'")
connection.close()
```

Highlighted on the slide: `('localhost')`, `queue='hello', durable=True`, and the `exchange='' / routing_key='hello' / body='Hello World!'` arguments.

## Slide 10 — (1) Hello world: Consumer (C)

```python
#!/usr/bin/env python
import pika, sys, os

def main():
    connection = pika.BlockingConnection(pika.ConnectionParameters(host='localhost'))
    channel = connection.channel()

    channel.queue_declare(queue='hello', durable=True)

    def callback(ch, method, properties, body):
        print(" [x] Received %r" % body)

    channel.basic_consume(queue='hello', on_message_callback=callback, auto_ack=True)

    print(' [*] Waiting for messages. To exit press CTRL+C')
    channel.start_consuming()

if __name__ == '__main__':
    try:
        main()
    except KeyboardInterrupt:
        print('Interrupted')
        try:
            sys.exit(0)
        except SystemExit:
            os._exit(0)
```

Highlighted on the slide: `host='localhost'`, `queue='hello', durable=True`, the `callback` function, `on_message_callback=callback`, `auto_ack=True`, and `channel.start_consuming()`.

- This lab uses push delivery through `basic_consume`. RabbitMQ also offers polling through `basic_get()`

# Part 3 — (2) Work queue / Task queue

## Slide 12 — (2) Work queue / Task queue

Pattern: P → queue → C1, C2 — The competing consumer pattern.

```sh
python 2_Worker.py
python 2_Worker.py
…
python 2_TaskQueue.py
```

- The assumption behind a work queue is that each task is delivered to exactly one worker.
- Round robin dispatching

## Slide 13 — (2) Work queue / Task queue (cont.): Producer (P)

```python
#!/usr/bin/env python
import pika
import sys

connection = pika.BlockingConnection(
    pika.ConnectionParameters(host='localhost'))
channel = connection.channel()

channel.queue_declare(queue='task_queue', durable=True)
                                                        #make queue persistent
message = ' '.join(sys.argv[1:]) or "Hello World!"
channel.basic_publish(
    exchange='',
    routing_key='task_queue',
    body=message,
    properties=pika.BasicProperties(
        delivery_mode=2,  # make message persistent
    ))
print(" [x] Sent %r" % message)
connection.close()
```

- `durable=True` — To ensure if RabbitMQ quits or crashes, it won't forget queues
- `delivery_mode=2` — Message will be stored to disk. (`pika.spec.PERSISTENT_DELIVERY_MODE`)

Highlighted on the slide: `'task_queue'`, `durable=True`, the `message = …` line, `body=message`, and `delivery_mode=2`.

## Slide 14 — (2) Work queue / Task queue (cont.): Consumer (C)

```python
#!/usr/bin/env python
import pika
import time

connection = pika.BlockingConnection(
    pika.ConnectionParameters(host='localhost'))
channel = connection.channel()

channel.queue_declare(queue='task_queue', durable=True)
print(' [*] Waiting for messages. To exit press CTRL+C')


def callback(ch, method, properties, body):
    print(" [x] Received %r" % body.decode())
    time.sleep(body.count(b'.'))
    print(" [x] Done")
    ch.basic_ack(delivery_tag=method.delivery_tag)


channel.basic_qos(prefetch_count=1)
channel.basic_consume(queue='task_queue', on_message_callback=callback)

channel.start_consuming()
```

- `durable=True` — To ensure if RabbitMQ quits or crashes, it won't forget queues
- `ch.basic_ack(delivery_tag=method.delivery_tag)` — To ensure that worker will send ack when completing the task.

Highlighted on the slide: `'task_queue'`, `durable=True`, the whole `callback` function with the `basic_ack` line, and the `basic_consume(...)` line.

## Slide 17 — Different stages related to Producer & Message Broekr & Consumer

| Mechanism | What it protects | What it does not prove |
|---|---|---|
| **Durable queue** | Queue survives restart | Every message survives |
| **Persistent message** | Message is eligible to survive restart in a durable queue | Producer knows it was safely accepted |
| **Publisher confirm** | Producer knows the broker accepted responsibility | Consumer completed the work |
| **Consumer acknowledgement** | Broker is told processing completed | Business effects happened exactly once |

# Part 4 — (3) Publish/Subscribe (fanout)

## Slide 19 — (3) Publish/Subscribe (fanout): Producer (P)

Pattern: P → X → two queues via *binding*. Exchange type: direct, topic, headers, **fanout**. Run `python 3_Publish_broadcast_log.py` and `python 3_Subscribe_log.py`.

- RabbitMQ will deliver a message to multiple consumers.

```sh
docker exec rabbitmq-lab rabbitmqctl list_exchanges
docker exec rabbitmq-lab rabbitmqctl list_bindings
```

```python
#!/usr/bin/env python
import pika
import sys

connection = pika.BlockingConnection(
    pika.ConnectionParameters(host='localhost'))
channel = connection.channel()

channel.exchange_declare(exchange='logs', exchange_type='fanout')

message = ' '.join(sys.argv[1:]) or "info: Hello World!"
channel.basic_publish(exchange='logs', routing_key='', body=message)
print(" [x] Sent %r" % message)
connection.close()
```

Highlighted on the slide: the `channel.exchange_declare(exchange='logs', exchange_type='fanout')` line.

- The use of exchange introduces the full messaging model in Rabbit.
- Core idea is that a producer never send any messages directly to a queue..
- The exchange routes a copy to every bound queue.

## Slide 20 — (3) Publish/Subscribe (fanout) (cont.): Consumer (C)

```python
#!/usr/bin/env python
import pika

connection = pika.BlockingConnection(
    pika.ConnectionParameters(host='localhost'))
channel = connection.channel()

channel.exchange_declare(exchange='logs', exchange_type='fanout')

result = channel.queue_declare(queue='', exclusive=True)
queue_name = result.method.queue

channel.queue_bind(exchange='logs', queue=queue_name)

print(' [*] Waiting for logs. To exit press CTRL+C')

def callback(ch, method, properties, body):
    print(" [x] %r" % body)

channel.basic_consume(
    queue=queue_name, on_message_callback=callback, auto_ack=True)

channel.start_consuming()
```

Highlighted on the slide: the `exchange_declare(...)` line, the `queue_declare(queue='', exclusive=True)` line, and the `queue_bind(...)` line.

- Temporary subscriptions — We want to hear all messages and only the current flowing messages not the older ones. (แปลว่า?)
- `queue=''`, `exclusive=True` — Let the server choose the random queue name and this queue will be deleted when the consumer's connection is closed.
- `channel.queue_bind(exchange='logs', queue=queue_name)` — Bind exchange with queue

# Part 5 — (4) Routing

## Slide 22 — (4) Routing: Producer (P)

Pattern: P → X (type=direct) → Q1 via `orange`, Q2 via `black`, `green` → C1, C2. Exchange type: **direct**, topic, headers, fanout; *binding key == routing key*. Run `python 4_Publish_direct_log.py` and `python 4_Subscrib_direct_log.py`.

```python
#!/usr/bin/env python
import pika
import sys

connection = pika.BlockingConnection(
    pika.ConnectionParameters(host='localhost'))
channel = connection.channel()

channel.exchange_declare(exchange='direct_logs', exchange_type='direct')

severity = sys.argv[1] if len(sys.argv) > 1 else 'info'
message = ' '.join(sys.argv[2:]) or 'Hello World!'
channel.basic_publish(
    exchange='direct_logs', routing_key=severity, body=message)
print(" [x] Sent %r:%r" % (severity, message))
connection.close()
```

Highlighted on the slide: the `exchange_declare(exchange='direct_logs', exchange_type='direct')` line, the `severity = …` line, and `exchange='direct_logs', routing_key=severity, body=message`.

## Slide 23 — (4) Routing: Consumer (C)

```python
#!/usr/bin/env python
import pika
import sys

connection = pika.BlockingConnection(
    pika.ConnectionParameters(host='localhost'))
channel = connection.channel()

channel.exchange_declare(exchange='direct_logs', exchange_type='direct')

result = channel.queue_declare(queue='', exclusive=True)
queue_name = result.method.queue

severities = sys.argv[1:]
if not severities:
    sys.stderr.write("Usage: %s [info] [warning] [error]\n" % sys.argv[0])
    sys.exit(1)

for severity in severities:
    channel.queue_bind(
        exchange='direct_logs', queue=queue_name, routing_key=severity)

print(' [*] Waiting for logs. To exit press CTRL+C')


def callback(ch, method, properties, body):
    print(" [x] %r:%r" % (method.routing_key, body))


channel.basic_consume(
    queue=queue_name, on_message_callback=callback, auto_ack=True)

channel.start_consuming()
```

Highlighted on the slide: the `exchange_declare(...)` line, the `queue_declare(queue='', exclusive=True)` line, `severities = sys.argv[1:]`, and `exchange='direct_logs', queue=queue_name, routing_key=severity`.

# Part 6 — (5) Topic

## Slide 25 — (5) Topic: Producer

Pattern: P → X (type=topic) → Q1 via `*.orange.*`, Q2 via `*.*.rabbit`, `lazy.#` → C1, C2. `*` Can substitute for exactly one word; `#` Can substitute for zero or more words. Run `python 5_Publish_topic_log.py` and `python 5_Subscribe_topic_log.py`.

```python
#!/usr/bin/env python
import pika
import sys

connection = pika.BlockingConnection(
    pika.ConnectionParameters(host='localhost'))
channel = connection.channel()

channel.exchange_declare(exchange='topic_logs', exchange_type='topic')

routing_key = sys.argv[1] if len(sys.argv) > 2 else 'anonymous.info'
message = ' '.join(sys.argv[2:]) or 'Hello World!'
channel.basic_publish(
    exchange='topic_logs', routing_key=routing_key, body=message)
print(" [x] Sent %r:%r" % (routing_key, message))
connection.close()
```

Highlighted on the slide: the `exchange_declare(exchange='topic_logs', exchange_type='topic')` line and the `routing_key = … / message = … / channel.basic_publish(...)` block.

## Slide 26 — (5) Topic: Consumer

```python
#!/usr/bin/env python
import pika
import sys

connection = pika.BlockingConnection(
    pika.ConnectionParameters(host='localhost'))
channel = connection.channel()

channel.exchange_declare(exchange='topic_logs', exchange_type='topic')

result = channel.queue_declare('', exclusive=True)
queue_name = result.method.queue

binding_keys = sys.argv[1:]
if not binding_keys:
    sys.stderr.write("Usage: %s [binding_key]...\n" % sys.argv[0])
    sys.exit(1)

for binding_key in binding_keys:
    channel.queue_bind(
        exchange='topic_logs', queue=queue_name, routing_key=binding_key)

print(' [*] Waiting for logs. To exit press CTRL+C')


def callback(ch, method, properties, body):
    print(" [x] %r:%r" % (method.routing_key, body))


channel.basic_consume(
    queue=queue_name, on_message_callback=callback, auto_ack=True)

channel.start_consuming()
```

Highlighted on the slide: the `exchange_declare(...)` line and the `for binding_key in binding_keys: channel.queue_bind(...)` loop.
