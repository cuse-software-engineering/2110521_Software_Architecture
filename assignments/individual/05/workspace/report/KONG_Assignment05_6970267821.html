2. Step 0-1: ติดตั้ง Docker, Node.js และสร้าง container ของ Postgres 9.6 และ Kong

3. Step 2: ติดตั้ง Konga และเชื่อมต่อกับ Kong

4. Start HTTP / REST / gRPC services ด้วย Node.js (2.2 f)

start service ทั้ง 4 ตัวจาก source code ของอาจารย์ (SimpleServices) ค้างไว้ใน background แล้วตรวจสอบว่าเรียกตรง ๆ ผ่าน IP ของเครื่องได้

cd SimpleHTTP   && node main1.js            # Hello World from Service1  :8081
cd SimpleHTTP   && node main2.js            # Hello World from Service2  :8082
cd SimpleREST   && node app.js              # express REST /account      :3000
cd SimplegRPC/node && node greeter_server.js # helloworld.Greeter/SayHello :50051

5. Step 3: สร้าง Service และ Route สำหรับ HTTP (httpservice1 → :8081) ด้วย Konga

6. Step 4: Upstream (load balancer) ไปที่ :8081 และ :8082

7. Step 5: Service และ Route สำหรับ REST (restservice → :3000)

8. Step 6: Service และ Route สำหรับ gRPC (grpcservice → :50051)

Kong รับ gRPC ที่ port 9080 (http2) ซึ่งคำสั่งใน PDF publish ไว้ที่ 127.0.0.1:9080 เท่านั้น การทดสอบ gRPC จึงเรียกที่ localhost:9080 ส่วน service ปลายทางยังชี้ไปที่ IP ของเครื่อง สำหรับ route ต้องตั้ง protocols = grpc, grpcs และ strip path = NO เพราะ path /helloworld.Greeter คือชื่อ service ของ gRPC ที่ต้องส่งต่อไปทั้งก้อน

9. สรุป Services และ Routes ทั้งหมดใน Kong (หน้าจอที่โจทย์ต้องการ)

10. Step 7-8: Basic Authentication และ Key Authentication ของ consumer

สร้าง consumer ชื่อ Bob ให้ credentials สองแบบ (basic-auth: bob / bob1234 และ api key: bob-secret-key-123) แล้วเปิด plugin basic-auth ที่ restservice และ key-auth ที่ httpservice1 จากนั้นทดสอบว่าถ้าไม่ส่ง credentials จะได้ 401 และเมื่อส่งถูกต้องจะได้ 200
