# ADR Template (Nygard format)

> Converted from `ADR_template_Nygard-13578-16615354705563.docx`. The Architecture Decision Record template handed out in the course, following Michael Nygard's format (Title, Context, Decision, Status, Consequences) with the course's own guidance under each heading.

---

## Title

highlight the issue you are making decision

## Context

describes the force at play, e.g., technological, political, social and project local. / assumptions / constraints

## Decision

describes responses to these forces in full sentences with active voices.

## Status

- **proposed:** if the project stakeholders haven't agreed with it yet.
- **accepted:** if it is agreed.
- **deprecated or superseded:** if it is replaced by a new ADR.
- **WIP:** if it is during gathering information / on-going / haven't decided yet

## Consequences

describes the resulting context, after applying the decision. All consequences: positives and negatives should be listed here.
