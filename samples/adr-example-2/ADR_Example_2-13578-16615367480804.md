## ADR 1 — Backend Framework

**Context**
The team wants to use a programming language and framework apart from Javascript's NodeJS and Express which we haven't tried before but also ease of learning due to the limited time of the project. The team has come up with the following alternatives; Python's Django and Java's Spring Boot. Since the team has some experience with the languages, we concluded that it won't require a lot of time to get familiar with the frameworks.

**Decision**
Decided on Django as it is a popular framework with comprehensive documents and tutorials. Also, the team already has an environment and IDE that is ready for developing python projects.

**Status**
Accepted.

**Consequences**
The team has to prepare to learn and experiment with Django while developing the project simultaneously. There's quite a possibility that we might face some framework-specific issues that we've never encountered before, and thus, may consume quite a time to fix the problem.

## ADR 2 — Frontend Framework

**Context**
From previous projects, we've been using raw CSS, HTML and JS along with view engines such as EJS and Handlebar for frontend development. Now we think it's time to start using some frameworks for development with the same constraint as the backend framework which is something new and easy to learn. We've finally come up with alternatives which are AngularJS, React and VueJS.

**Decision**
Decided on VueJS as the team agreed that AngularJS has quite a steep learning curve and the team has some experience with React during internship but we want to try something new.

**Status**
Accepted

**Consequences**
The team has never used two frameworks with different programming languages before. Therefore, it could be some learning curve with making the two work well together. Also, having no experience with VueJS can cause some confusion at first. However, the team expects this problem is not significant and manageable.
